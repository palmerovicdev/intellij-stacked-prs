# Open pull requests view

Objective: add a separate Upstack view for open pull requests while preserving stacked PR behavior. Branch: `feat/pr-templates` (pre-existing). Delivery: ask-on-risk; forecast exceeds 400 authored lines. Runner: `./gradlew test` and focused tests.

## Specs

- **S1 — Separate view.** User: "vamos a ver si podemos hacer un modo en el que se listen todos los PR que están actualmente abiertos, en vez de los del stack"; "agregar la posibilidad de tener una vista de prs diferente de la de intellij idea que funcione bien de verdad". List every open PR of the selected repository, including pagination; represent loading, empty and failure separately.
- **S2 — Preserve stacks.** User: "fijate que deben mantenerse todas las funciones de stacked prs". Existing stack views, commands and navigation must continue to work.
- **S3 — Review comments.** User: "una de las cosas que seria importante es que salgan lso comentarios en codigo que se hagan en el visualizador de cambios para poder revisar que pasa". Investigate the IDE review integration and display PR review conversations in context; do not count a plain Git diff as equivalent.
- **S4 — Port capabilities.** User: "Lo mismo que tenemos ya para los stack"; "create the title and the description of the PR". The candidates and unresolved choices are recorded in `docs/plan-modo-prs.md`; implement applicable individual-PR capabilities in coherent slices, without presenting stack-specific operations as ordinary PR operations.
- **S5 — Readable PR rows.** User: "pon mas informacion y haz los chips mejores, como hacemos con lo de stacks, debe poderse ver bien"; "mira el de intellij por defecto, vez que pone eso bonito y mas facil de entender". Show more useful PR information using Upstack's existing chips, with a compact visual hierarchy inspired by the supplied IntelliJ screenshot and without overflowing a narrow panel.
- **S6 — Edit PR dialog.** User: "en este dialog que no se muestre el contenido abajo asi, ya con el campo de texto es suficiente"; "y el campo de texto se debe agrandar con la ventana, para que se pueda ver mejor si se quiere"; "esto ultimo ya esta". Do not duplicate the description below its editor. Verify existing resize behavior before changing it; continue submitting the full description.
